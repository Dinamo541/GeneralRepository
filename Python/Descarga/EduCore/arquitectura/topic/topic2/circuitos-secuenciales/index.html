Circuitos Secuenciales - Flip-Flops, Contadores y Registros

1. Introducción a los Circuitos Secuenciales

A diferencia de los circuitos combinatorios, los circuitos secuenciales tienen memoria. Sus salidas dependen no solo de las entradas actuales, sino también del estado anterior.

Características principales:

  • Incluyen elementos de almacenamiento (biestables).
  • Funcionan con una señal de reloj (clock) que sincroniza los cambios.
  • Se utilizan para construir memoria, contadores, registros, etc.

Componentes Básicos de un Circuito Secuencial:

Entradas → [ Circuito Combinatorio ] → Salidas
↑ ↓
└── [ Memoria ] ──┘

2. Seguros (Latches)

Un latch es el circuito básico de almacenamiento. Es un biestable sin reloj.

2.1 Latch SR (Set-Reset)

Entradas:
- $S$ (Set): Activa la salida Q = 1
- $R$ (Reset): Activa la salida Q = 0
- $Q$: Salida normal
- $\overline{Q}$: Salida complementaria

Tabla de Verdad del Latch SR:

S R Q Q' Estado
0 0 Q Q' No hay cambio
0 1 0 1 Reset
1 0 1 0 Set
1 1 0 0 Estado inválido

2.2 Latch SR con Entrada de Control (Enable)

Permite habilitar o deshabilitar el latch.

E S R Estado siguiente de Q
0 X X No hay cambio
1 0 0 No hay cambio
1 0 1 0 (Reset)
1 1 0 1 (Set)
1 1 1 Indeterminado

2.3 Latch D (Data)

Elimina el estado inválido del latch SR utilizando una entrada única D.

Entrada: D
Salida: Q = D (cuando E = 1)

Tabla de Verdad:

D Q (siguiente)
0 0
1 1

Diagrama: Se construye con un latch SR y una compuerta NOT.
D ──┬── S ──┐
│ │
└── NOT ── R ── [Latch SR] ── Q

3. Flip-Flops (Multivibradores Biestables)

Un flip-flop es un latch sincronizado por una señal de reloj. Los cambios ocurren solo en los flancos del reloj.

3.1 Flip-Flop D (Data)

El más común y sencillo. La salida Q toma el valor de D en el flanco activo del reloj.

Tabla de Características:

D Q(t+1) Operación
0 0 Reset
1 1 Set

Símbolo:
D ──|FF D|── Q
| |
└── CP (Reloj)

3.2 Flip-Flop JK

Elimina la condición inválida del flip-flop SR, permitiendo todas las combinaciones de entrada.

Tabla de Características:

J K Q(t+1) Operación
0 0 Q(t) No hay cambio
0 1 0 Reset
1 0 1 Set
1 1 $\overline{Q(t)}$ Toggle (Complemento)

Símbolo:
J ──|FF JK|── Q
K ──| |
└── CP (Reloj)

3.3 Flip-Flop T (Toggle)

Cambia de estado cuando T = 1.

Tabla de Características:

T Q(t+1) Operación
0 Q(t) No hay cambio
1 $\overline{Q(t)}$ Toggle

Símbolo:
T ──|FF T|── Q
| |
└── CP (Reloj)

3.4 Flip-Flop RS (Set-Reset)

Similar al latch SR pero sincronizado por reloj. La condición J=1, K=1 es inválida.

Tabla de Características:

R S Q(t+1) Operación
0 0 Q(t) No hay cambio
0 1 1 Set
1 0 0 Reset
1 1 - Indeterminado

4. Tablas de Excitación

Las tablas de excitación indican qué valores de entrada son necesarios para lograr una transición de estado deseada.

Transición FF D FF JK FF T FF RS
0 → 0 D=0 J=0, K=X T=0 R=X, S=0
0 → 1 D=1 J=1, K=X T=1 R=0, S=1
1 → 0 D=0 J=X, K=1 T=1 R=1, S=0
1 → 1 D=1 J=X, K=0 T=0 R=0, S=X

X = Don't Care (puede ser 0 o 1)

5. Contadores

Un contador es un circuito secuencial que recorre una secuencia predeterminada de estados.

5.1 Contador Binario de 2 bits

Secuencia: 00 → 01 → 10 → 11 → 00

Tabla de Estado:

Estado Presente Estado Siguiente
00 01
01 10
10 11
11 00

Implementación con FF T:

  • $T_1 = 1$ (siempre toggle)
  • $T_0 = Q_1$ (toggle cuando Q1 = 1)

5.2 Contador de Década (0-9)

Cuenta del 0 al 9 (0000 a 1001) y luego regresa a 0.

Secuencia: 0000 → 0001 → 0010 → ... → 1001 → 0000

5.3 Contador Ascendente/Descendente (Up/Down)

Puede contar hacia arriba o hacia abajo según una entrada de control.

6. Registros

Un registro es un conjunto de flip-flops que almacenan un dato binario de varios bits.

6.1 Registro de Almacenamiento (Paralelo)

Almacena y entrega datos en paralelo (todos los bits al mismo tiempo).
D3 D2 D1 D0 ── [ FF3 FF2 FF1 FF0 ] ── Q3 Q2 Q1 Q0

6.2 Registro de Desplazamiento (Shift Register)

Los bits se mueven de una posición a otra en cada pulso de reloj.

Tipos:
- Desplazamiento a la derecha: Serie → → →
- Desplazamiento a la izquierda: ← ← ← Serie
- Rotación: Los bits que salen vuelven a entrar.

Aplicaciones:
- Conversión serie-paralelo
- Multiplicación y división por 2
- Memoria FIFO

6.3 Memoria de 4 bits (Ejemplo)

Construida con 4 flip-flops D.
D3 ──|FF|── Q3
D2 ──|FF|── Q2
D1 ──|FF|── Q1
D0 ──|FF|── Q0

7. Máquinas de Estado Finito (FSM)

Una FSM es un modelo matemático que describe el comportamiento de un circuito secuencial.

Componentes de una FSM:

  1. Conjunto de estados: Posibles estados del sistema.
  2. Conjunto de entradas: Señales que llegan al sistema.
  3. Función de transición: Estado siguiente = f(estado actual, entradas).
  4. Conjunto de salidas: Señales que produce el sistema.

Tipos de FSM:

  • Modelo Mealy: Las salidas dependen del estado actual y de las entradas.
  • Modelo Moore: Las salidas dependen solo del estado actual.

Diagrama de Estados

Representación gráfica donde:
- Círculos representan estados.
- Flechas representan transiciones.
- Etiquetas en las flechas muestran entrada/salida.

Ejemplo: Máquina expendedora de refrescos.

8. Procedimiento de Diseño Secuencial

Pasos para diseñar un circuito secuencial:

  1. Crear el diagrama de estados a partir de las especificaciones.

  2. Crear la tabla de estados a partir del diagrama.

  3. Seleccionar los flip-flops (tipo D, JK, T, o RS).

  4. Obtener las ecuaciones de entrada para cada flip-flop.

  5. Simplificar las ecuaciones usando álgebra booleana o mapas K.

  6. Dibujar el diagrama lógico implementando las ecuaciones.

Ejemplo de Diseño con FF D:

  1. Tabla de estados → Estado siguiente
  2. Para FF D: $D = Q(t+1)$
  3. Derivar D como función de las entradas y el estado actual.
  4. Implementar con compuertas lógicas.

Ejemplo de Diseño con FF JK:

  1. Tabla de estados → Estado siguiente
  2. Usar tabla de excitación JK para obtener J y K.
  3. Derivar J y K como funciones de las entradas y el estado actual.
  4. Implementar con compuertas lógicas.

9. Diagramas de Estado

Notación:

  • Estado: $S_0, S_1, S_2, \ldots$
  • Transición: $S_i \xrightarrow{Entrada/Salida} S_j$

10. Ejercicios de Práctica

  1. Diseña un flip-flop T usando un flip-flop JK.

  2. Dibuja el diagrama de estados de un contador que recorra la secuencia: 0 → 2 → 4 → 6 → 0.

  3. Diseña un registro de desplazamiento de 4 bits con carga en paralelo.

  4. Diseña un detector de secuencia "101" con FF JK.

  5. Implementa un contador ascendente/descendente de 3 bits con FF T.

11. Resumen de Flip-Flops

Tipo Símbolo Ecuación de Estado Uso Principal
D $D \to Q$ $Q(t+1) = D$ Registros, memorias
JK $J, K \to Q$ $Q(t+1) = J\overline{Q} + \overline{K}Q$ Contadores, secuenciadores
T $T \to Q$ $Q(t+1) = T \oplus Q$ Contadores
RS $R, S \to Q$ $Q(t+1) = S + \overline{R}Q$ Memoria básica
