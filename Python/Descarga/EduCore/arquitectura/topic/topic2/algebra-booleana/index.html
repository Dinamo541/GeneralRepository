Álgebra Booleana

1. Introducción al Álgebra Booleana

El Álgebra Booleana es un sistema matemático que trabaja con variables binarias y operaciones lógicas. Fue desarrollada por George Boole en el siglo XIX y es fundamental para el diseño y análisis de circuitos digitales.

Características del Álgebra Booleana:

  • Las variables toman solo dos valores: 0 y 1.
  • Las operaciones básicas son: AND, OR y NOT.
  • Se utiliza para simplificar expresiones lógicas y reducir el número de compuertas necesarias.

2. Funciones Booleanas

Una función booleana es una expresión algebraica formada con variables binarias, constantes (0 y 1), símbolos de operaciones lógicas, paréntesis y un signo igual.

Ejemplo de Función Booleana

$
F = X + \overline{Y}Z
$

Esta función tiene tres variables (X, Y, Z). Para evaluarla, se construye una tabla de verdad con todas las combinaciones posibles.

1 1 1 0 0 1

4. Identidades Básicas del Álgebra Booleana

# Identidad # Identidad (Dual)
1 $X + 0 = X$ 2 $X \cdot 1 = X$
3 $X + 1 = 1$ 4 $X \cdot 0 = 0$
5 $X + X = X$ 6 $X \cdot X = X$
7 $X + \overline{X} = 1$ 8 $X \cdot \overline{X} = 0$
9 $\overline{\overline{X}} = X$
10 $X + Y = Y + X$ 11 $X \cdot Y = Y \cdot X$ (Conmutativa)
12 $X + (Y + Z) = (X + Y) + Z$ 13 $X \cdot (Y \cdot Z) = (X \cdot Y) \cdot Z$ (Asociativa)
14 $X \cdot (Y + Z) = X \cdot Y + X \cdot Z$ 15 $X + Y \cdot Z = (X + Y) \cdot (X + Z)$ (Distributiva)
16 $\overline{X + Y} = \overline{X} \cdot \overline{Y}$ 17 $\overline{X \cdot Y} = \overline{X} + \overline{Y}$ (DeMorgan)

Teoremas de DeMorgan (Los más importantes)

Los teoremas de DeMorgan permiten transformar expresiones con negaciones:

  1. $\overline{X + Y} = \overline{X} \cdot \overline{Y}$ (El complemento de una suma es el producto de los complementos)
  2. $\overline{X \cdot Y} = \overline{X} + \overline{Y}$ (El complemento de un producto es la suma de los complementos)

Regla práctica: Para aplicar DeMorgan, se cambia la operación (AND ↔ OR) y se complementan todas las variables.

5. Manipulación Algebraica

El Álgebra Booleana es una herramienta útil para simplificar circuitos digitales. Al simplificar, se reduce el número de compuertas necesarias.

Ejemplo 1 de Simplificación

Según ejercicio de la Alarma, si

$
F = \overline X Y Z + X \overline Y \overline Z + X \overline Y Z + XY \overline Z + XYZ
$

Entonces,

  1. Agrupar términos:
    $F = \overline X Y Z + (X \overline Y \overline Z + X \overline Y Z) + (XY \overline Z + XYZ)$

  2. Factorizar por pares:
    $F = \overline X Y Z + X \overline Y (\overline Z + Z) + XY (\overline Z + Z)$

  3. Aplicar identidad ($\overline{X} + X = 1$):
    $F = \overline X Y Z + X \overline Y (1) + XY (1)$

  4. Factorizar nuevamente:
    $F = \overline X Y Z + X (\overline Y + Y)$

  5. Aplicar identidad ($\overline{Y} + Y = 1$):
    $F = \overline X Y Z + X (1)$

  6. Aplicar distributiva
    $F = (\overline X + X) (Y Z + X) $

  7. Resultado final
    $F = X + Y Z$

Ejemplo 2 de Simplificación

Simplificar la siguiente expresión:

$
F = ( \overline { A + \overline { B \overline C + C D }} ) + ( \overline A B )
$

Paso a paso:

  1. Aplicar DeMorgan:
    $F = ( \overline A (\overline{ \overline { B \overline C + C D }} )) + ( \overline A B )$

  2. Doble negación:
    $F = \overline A ( B \overline C + C D ) + \overline A B $

  3. Aplicar distributiva:
    $F = \overline A B \overline C + \overline A C D + \overline A B $

  4. Factorizar:
    $F = \overline A B (\overline C + 1) + \overline A C D $

  5. Aplicar identidad $(\overline C + 1) = 1$:
    $F = \overline A B (1) + \overline A C D $

  6. Resultado final:
    $F = \overline A B + \overline A C D $ o $F = \overline A (B + C D ) $

6. Ejercicios de Simplificación

Simplifica las siguientes expresiones booleanas:

  1. $F = XYZ + \overline{X}YZ + X\overline{Z}$

  2. $F = \overline{X}Y\overline{Z} + \overline{X}Y + X(\overline{Y}) (\overline{Z})$

  3. $F = (\overline{X + Y})(\overline{X} + \overline{Y})$

  4. $F = \overline{(BC)} + C + [(\overline{(AD)} + B)\overline{(AD)}]$

  5. $F = ( \overline { \overline A + \overline { \overline B C + C D }} ) + \overline {( A + B )} $
