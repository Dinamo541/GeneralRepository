Simplificación con Mapas de Karnaugh

1. Introducción a los Mapas de Karnaugh

El Mapa de Karnaugh (o Mapa K) es un método gráfico para simplificar expresiones booleanas. Fue desarrollado por Maurice Karnaugh en 1953 y es especialmente útil para funciones de hasta 4 variables.

Ventajas del Mapa K sobre la manipulación algebraica:

  • Es un procedimiento directo y sistemático.
  • No requiere reglas complejas.
  • Permite visualizar fácilmente los términos que se pueden combinar.
  • Reduce el riesgo de cometer errores.

Desventajas:

  • Se vuelve complicado para más de 5 variables.
  • Requiere práctica para dominarlo completamente.

2. Estructura de un Mapa de Karnaugh

El mapa de Karnaugh es una matriz donde cada celda representa un minitérmino. Las celdas adyacentes difieren en una sola variable.

Mapa de 2 Variables

Y = 0 Y = 1
X = 0 $m_0$ (00) $m_1$ (01)
X = 1 $m_2$ (10) $m_3$ (11)

Mapa de 3 Variables

YZ = 00 YZ = 01 YZ = 11 YZ = 10
X = 0 $m_0$ $m_1$ $m_3$ $m_2$
X = 1 $m_4$ $m_5$ $m_7$ $m_6$

Mapa de 4 Variables

CD = 00 CD = 01 CD = 11 CD = 10
AB = 00 $m_0$ $m_1$ $m_3$ $m_2$
AB = 01 $m_4$ $m_5$ $m_7$ $m_6$
AB = 11 $m_{12}$ $m_{13}$ $m_{15}$ $m_{14}$
AB = 10 $m_8$ $m_9$ $m_{11}$ $m_{10}$

Nota sobre la Numeración (Código Gray)

Los números en el mapa siguen el código Gray, donde solo cambia un bit entre celdas adyacentes.

Orden de las columnas: 00 → 01 → 11 → 10

Importante: Las celdas en los bordes opuestos del mapa también son adyacentes (como si el mapa estuviera enrollado en un cilindro o toroide).

3. Procedimiento de Simplificación

Pasos para simplificar con un Mapa K:

  1. Crear el mapa: Dibujar la matriz según el número de variables.
  2. Llenar el mapa: Colocar 1 en las celdas correspondientes a los minitérminos de la función (los 0 se dejan vacíos).
  3. Agrupar los 1s: Formar grupos rectangulares de 1, 2, 4, 8, 16, etc. (potencias de 2).
  4. Reglas de agrupación:
    • Los grupos deben ser lo más grandes posible.
    • Los grupos pueden compartir celdas.
    • Los grupos pueden enrollarse alrededor de los bordes del mapa
    • Un grupo de $2^n$ celdas elimina $n$ variables.
  5. Escribir la expresión simplificada: Cada grupo se convierte en un término producto.

4. Ejemplos de Simplificación

Ejemplo 1: Simplificar $F(X, Y, Z) = \Sigma m(3, 4, 6, 7)$

Mapa K de 3 variables:

YZ = 00 YZ = 01 YZ = 11 YZ = 10
X = 0 0 0 1 0
X = 1 1 0 1 1

Agrupaciones:
- Grupo 1: Celdas (4, 6) → $X\overline{Z}$
- Grupo 2: Celdas (3, 7) → $YZ$

Resultado: $F = X\overline{Z} + YZ$

Ejemplo 2: Simplificar $F(X, Y, Z) = \Sigma m(3, 4, 5, 6, 7)$

Mapa K:

YZ = 00 YZ = 01 YZ = 11 YZ = 10
X = 0 0 0 1 0
X = 1 1 1 1 1

Agrupaciones:
- Grupo 1: Celdas (4, 5, 6, 7) → $X$
- Grupo 2: Celdas (3, 7) → $YZ$

Resultado: $F = X + YZ$

5. Condiciones "No Importa" (Don't Care)

En algunos circuitos, ciertas combinaciones de entrada nunca ocurren. Estas condiciones se llaman "no importa" y se representan con una X en el mapa.

Regla para las "X":

  • Se pueden tratar como 0 o 1, lo que sea más conveniente para formar grupos más grandes.

Ejemplo con Condiciones "No Importa":

Simplificar $F(W, X, Y, Z) = \Sigma m(1, 3, 7, 11, 15)$ con condiciones no importa $d(W, X, Y, Z) = \Sigma m(0, 2, 5)$

YZ = 00 YZ = 01 YZ = 11 YZ = 10
WX = 00 X 1 1 X
WX = 01 0 X 1 0
WX = 11 0 0 1 0
WX = 10 0 0 1 0

Agrupaciones:
- Grupo 1: Celdas (1, 3, 5, 7) → $YZ$
- Grupo 2: Celdas (3, 7, 11, 15) → $WZ$

Resultado: $F = YZ + WZ$

6. Ejercicios de Práctica

Simplifica las siguientes funciones usando Mapas K:

  1. $F(X, Y, Z) = \Sigma m(0, 2, 4, 5, 6)$

  2. $F(X, Y, Z) = \Sigma m(1, 3, 4, 5, 6)$

  3. $F = ABC + \overline{B}CD + A\overline{B}CD + \overline{A}BC$

  4. $F(W, X, Y, Z) = \Sigma m(0, 1, 2, 4, 5, 6, 8, 9, 12, 13, 14)$

7. Resumen del Método

  1. Dibujar el mapa: Según el número de variables (2, 3, 4 o 5).
  2. Llenar con 1s y 0s (o Xs) según la función.
  3. Agrupar los 1s en grupos de potencias de 2.
  4. Leer la expresión: Cada grupo da un término producto.
  5. Eliminar variables: En un grupo de 2^n celdas, se eliminan las variables que cambian dentro del grupo.
