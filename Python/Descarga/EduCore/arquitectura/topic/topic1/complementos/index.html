Complementos (1's y 2's)

1. Introducción a los Complementos

Los complementos se utilizan en las computadoras digitales para simplificar la operación de sustracción (resta) y para realizar la manipulación lógica de datos.

Para cada sistema de base $r$, existen dos tipos de complementos:

  1. Complemento radical disminuido ($(r-1)$'s complement)
  2. Complemento radical ($r$'s complement)

En sistemas binarios (base 2), estos son conocidos como:
- Complemento a 1's
- Complemento a 2's

2. Complemento a 1's

El complemento a 1's de un número binario se obtiene invirtiendo cada bit (cambiando los 0s por 1s y los 1s por 0s).

Ejemplos:

Número Original Complemento a 1's
1011001 0100110
0001111 1110000

Regla:

$
\overline{N} = \text{Complemento a 1's de } N
$

3. Complemento a 2's

El complemento a 2's de un número binario se obtiene calculando el complemento a 1's y sumando 1 al resultado.

Fórmula:

$
\text{Complemento a 2's} = (\text{Complemento a 1's}) + 1
$

Ejemplo:

Calcular el complemento a 2's de $101100_2$.

  1. Complemento a 1's: $010011$
  2. Sumar 1: $010011 + 1 = 010100$

Resultado: El complemento a 2's de $101100_2$ es $010100_2$.

4. Uso de Complementos para Resta

Los complementos se utilizan para realizar restas de manera más eficiente en el hardware. En lugar de restar, se suma el complemento.

Método para restar $Y$ de $X$ ($X - Y$):

  1. Calcular el complemento a 2's de $Y$.
  2. Sumar $X$ con el complemento a 2's de $Y$.
  3. Si hay acarreo final, descartarlo (el resultado es positivo).
  4. Si no hay acarreo final, el resultado es negativo y se debe tomar el complemento a 2's del resultado obtenido.

Ejemplo 1: Resta con resultado positivo ($X > Y$)

Operación: Restar $Y = 1000011_2$ de $X = 1010100_2$
Operación: $1010100 - 1000011$

Paso 1: Alinear bits

Ambos números ya cuentan con la misma longitud (7 bits):
- X (minuendo): 1010100 (7 bits)
- Y (sustraendo): 1000011 (7 bits)

Paso 2: Complemento a 2 del sustraendo ($Y$)

  1. Complemento a 1 (invertir bits): 0111100
  2. Sumar 1: 0111100 + 1 = 0111101

Paso 3: Sumar $X$ + Complemento a 2 de $Y$

   1110000   (Acarreos)
    1010100  (X)
 +  0111101  (C2 de Y)
-----------
  1 0010001  (Suma con acarreo final)

Paso 4: Interpretación del resultado

  • Acarreo final: SÍ hay acarreo (el 1 de la izquierda). Se descarta y nos indica que el resultado es positivo.
  • Valor en binario: 0010001 ($17$ en decimal).

Ejemplo 2: Resta con resultado negativo ($X < Y$)

Operación: Restar $Y = 111011_2$ de $X = 110100_2$
Operación: $110100 - 111011$

Paso 1: Alinear bits

Ambos números ya cuentan con la misma longitud (7 bits):
- X (minuendo): 110100 (6 bits)
- Y (sustraendo): 111011 (6 bits)

Paso 2: Complemento a 2 del sustraendo ($Y$)

  1. Complemento a 1 (invertir bits): 000100
  2. Sumar 1: 000100 + 1 = 000101

Paso 3: Sumar $X$ + Complemento a 2 de $Y$

   000100   (Acarreos)
    110100  (X)
 +  000101  (C2 de Y)
----------
  0 111001  (Suma sin acarreo final)

Paso 4: Interpretación del resultado

  • Acarreo final: NO hay acarreo (0), el resultado es negativo. Esto indica que el resultado es negativo y está expresado en Complemento a 2.
  • Para obtener el valor absoluto: Aplicamos C2 al resultado (111001 $\rightarrow$ C1: 000110 + 1 = 000111 = $7$ decimal).
  • Resultado final: -7 (decimal) → 111001 (binario en C2)
