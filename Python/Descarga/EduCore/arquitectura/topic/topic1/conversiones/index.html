Conversiones entre Sistemas Numéricos

1. Introducción

La capacidad de convertir números entre diferentes sistemas numéricos es fundamental para entender cómo funciona la computadora a nivel interno. En esta lección aprenderemos a convertir entre los sistemas decimal, binario y hexadecimal.

2. Conversión de Binario a Decimal

Para convertir un número binario a decimal, se multiplica cada bit por 2 elevado a su posición (comenzando desde 0 para el bit menos significativo).

Fórmula General:

$
N_{10} = \sum_{i=0}^{n-1} b_i \times 2^i
$

Donde $b_i$ es el bit en la posición $i$.

Ejemplo:

Convertir $1011_2$ a decimal.

$
1011_2 = 1 \times 2^3 + 0 \times 2^2 + 1 \times 2^1 + 1 \times 2^0 = 8 + 0 + 2 + 1 = 11_{10}
$

3. Conversión de Decimal a Binario (Método de Divisiones Sucesivas)

Para convertir un número decimal a binario, se divide sucesivamente el número entre 2 y se toman los residuos de abajo hacia arriba.

Pasos:

  1. Dividir el número decimal entre 2.
  2. Escribir el cociente y el residuo.
  3. Repetir el proceso con el cociente hasta que sea 0.
  4. El número binario se forma con los residuos leídos de abajo hacia arriba.

Ejemplo:

Convertir $41_{10}$ a binario.

Operación Cociente Residuo
41 ÷ 2 20 1
20 ÷ 2 10 0
10 ÷ 2 5 0
5 ÷ 2 2 1
2 ÷ 2 1 0
1 ÷ 2 0 1

Resultado: $41_{10} = 101001_2$

4. Conversión de Binario a Hexadecimal

Para convertir binario a hexadecimal, se agrupan los bits en grupos de 4 (comenzando desde la derecha) y se convierten a su equivalente hexadecimal.

Tabla de Conversión (4 bits a Hex)

Ejemplo:

Convertir $101111_2$ a hexadecimal.

  1. Agrupar en 4 bits (rellenar con ceros a la izquierda si es necesario):
  2. $0010$ $1111$
  3. Convertir cada grupo:
  4. $0010_2 = 2_{16}$
  5. $1111_2 = F_{16}$

Resultado: $101111_2 = 2F_{16}$

5. Conversión de Hexadecimal a Binario

Para convertir hexadecimal a binario, se convierte cada dígito hexadecimal a su equivalente binario de 4 bits.

Ejemplo:

Convertir $5F_{16}$ a binario.

  • $5_{16} = 0101_2$
  • $F_{16} = 1111_2$

Resultado: $5F_{16} = 01011111_2$

6. Conversión de Decimal a Hexadecimal

Se puede hacer de dos formas:

Método 1: Decimal → Binario → Hexadecimal

  1. Convertir el número decimal a binario (divisiones sucesivas).
  2. Agrupar en 4 bits y convertir a hexadecimal.

Método 2: Divisiones Sucesivas por 16

Se divide el número decimal entre 16 sucesivamente, tomando los residuos.

Ejemplo:

Convertir $46687_{10}$ a hexadecimal.

Operación Cociente Residuo
46687 ÷ 16 2917 15 (F)
2917 ÷ 16 182 5
182 ÷ 16 11 6
11 ÷ 16 0 11 (B)

Resultado: $46687_{10} = B65F_{16}$
