Simbolización de Proposiciones

La simbolización es el proceso de traducir frases del lenguaje natural al lenguaje de la lógica proposicional.

Pasos para simbolizar

  1. Identificar las proposiciones simples
  2. Asignar variables (p, q, r, ...) a cada proposición simple
  3. Identificar las conectivas lógicas presentes
  4. Construir la fórmula lógica

Ejemplo 1:
"Si llueve, entonces me quedo en casa"
- p: "Llueve"
- q: "Me quedo en casa"
- Fórmula: p → q

Ejemplo 2:
"Estudio y apruebo el examen"
- p: "Estudio"
- q: "Apruebo el examen"
- Fórmula: p ∧ q

Ejemplo 3:
"No es cierto que hoy sea lunes y haya clases"
- p: "Hoy es lunes"
- q: "Hay clases"
- Fórmula: ¬(p ∧ q)

Tabla de símbolos

Conectiva Símbolo Lenguaje natural
Negación ¬ "no", "no es cierto que"
Conjunción ∧ "y", "pero", "además"
Disyunción inclusiva ∨ "o" (inclusivo)
Disyunción exclusiva ⊕ "o... pero no ambos"
Condicional → "si... entonces", "implica"
Bicondicional ↔ "si y solo si", "equivale"

Consideraciones importantes

1. Prioridad de operadores

Al igual que en aritmética, los operadores lógicos tienen un orden de precedencia:

  1. Negación (¬) - Mayor prioridad
  2. Conjunción (∧)
  3. Disyunción (∨)
  4. Condicional (→)
  5. Bicondicional (↔) - Menor prioridad

Ejemplo:
¬p ∧ q → r se interpreta como ((¬p) ∧ q) → r

2. Uso de paréntesis

Los paréntesis ayudan a evitar ambigüedades:

  • p ∧ (q ∨ r) ≠ (p ∧ q) ∨ r

📌 Ejercicio: Simboliza las siguientes frases:
1. "Si estudio pero no hago tareas, entonces no apruebo"
2. "Trabajo o estudio, pero no ambas cosas al mismo tiempo"
3. "Puedo viajar si y solo si tengo dinero y tiempo"
4. "No es cierto que haya clases y que sea feriado"
